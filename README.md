# ask-ui-kit

Framework-agnostic Web Components for AI chat interfaces — built with [Lit](https://lit.dev).

## Installation

```bash
npm install ask-ui-kit
```

## Usage

```html
<script type="module">
  import "ask-ui-kit";
</script>

<chat-message role="user" content="Hello, AI!"></chat-message>
<chat-message role="assistant" content="Hi there! How can I help?"></chat-message>
```

## Components

- `<chat-message>` — A chat bubble for user or assistant messages
- More coming soon...

## Development

```bash
npm install
npm run dev
```
